# 設計質感研究：motionsites.ai、React Bits、Uiverse

日期：2026-09-30

檢視三個網站，找出能提升ひとめぐり質感、又不違背我們設計原則（DESIGN.md §1、§9、§12，PLAN.md §6a）的做法。

## 結論先講

三個網站裡最有用的是 **React Bits（與它的 Vue 版 Vue Bits）** 的元件點子，其次是 **Uiverse** 的小元件與紋樣；**motionsites.ai** 是給 AI 產生行銷首頁用的 prompt 庫，風格和我們相反，幾乎不適用。

建議做的前五項（詳見「可以採用的」）：

1. **去過的「蓋章」動畫**：按下去過時，印章像橡皮章壓下去。這是本產品的招牌時刻（一巡り＝走一圈、蓋滿章）。
2. **地圖 ↔ 深度探索的畫面銜接**：用瀏覽器內建的 View Transitions，讓地區名稱從左上的地區標籤「長大」成深度探索頁的大標題，不需要任何套件。
3. **會動的指示線與數字**：分頁、段落目錄的底線滑到新位置；件數、去過數量換數字時滾動。
4. **和風紋樣與紙張質感**：地區海報區加極淡的青海波、麻の葉等紋樣，或細微的紙紋，靜態，不動。
5. **骨架載入**：把 9 處純文字「載入中」換成和內容同形狀的灰色骨架。

做法上**自己寫小元件，不引入 GSAP、three.js、ogl 等套件**：這些效果用 CSS 和瀏覽器原生 API 就做得到，而且 Vue Bits 的授權不適合把程式碼放進我們公開的 repo（見下方）。

## 三個網站是什麼

### motionsites.ai

- **性質**：付費的「AI 網站 prompt」庫。複製 prompt 貼進 Lovable、Bolt、Cursor、Claude，讓 AI 產生有動畫的行銷首頁。首頁標語是「Beautiful Website Prompts for Lovable, Bolt, Cursor, and Claude. Build Stunning 3d Websites With AI」。
- **內容**：Hero 區、Landing page、Footer 等區塊的 prompt，另有動態背景影片與 Lovable 範本。第三方評測記載 2026 年 7 月約有 364 個 prompt、159 支動態背景影片。
- **價格**：部分免費，其餘年費 149 美元起。
- **風格**：SaaS、Web3、玻璃擬態（glassmorphism）、3D、大面積漸層與影片背景。
- **對我們**：幾乎不適用。
  - 它的目標是「第一眼很炫」的行銷頁；我們是每天使用的工具，DESIGN.md §1 的原則是「內容先於介面」「沒有 AI 味」，§12 禁止漸層、毛玻璃。
  - 唯一可借鏡的是**版面結構**：大字標題＋一張代表照片的 hero，對應到我們深度探索頁的海報區（見「可以採用的」第 7 項）。

### React Bits（reactbits.dev）與 Vue Bits

- **性質**：開源的動畫元件庫，作者 David Haz。React 版約 170 個元件，官方 Vue 版 **Vue Bits** 有 90 個以上；我們用 Vue，所以對應的是 Vue Bits。
- **分類**：文字動畫、動畫、元件、背景四類。
- **安裝**：用 jsrepo CLI 或複製原始碼進專案，不是 npm 套件。
- **依賴**：很多元件依賴 GSAP、motion、three.js、ogl（WebGL）。例如 SplitText 需要 GSAP；Aurora、Galaxy 等背景需要 ogl 或 three.js。
- **授權：MIT + Commons Clause**。
  - 可以用在網站、包括商業用途。
  - 但**不可以「販售、再授權或再散布元件本身」**，包括「單獨、打包、範本或移植版」。
  - 我們的 repo 是公開的，把元件原始碼複製進來等於公開散布它的程式碼，界線模糊。**建議只參考點子、自己寫**，不直接複製。
- **對我們**：點子很多，但大部分是「炫」的效果（游標特效、WebGL 背景、玻璃、漸層光澤），和我們的原則衝突。少數安靜、有意義的可以借鏡（見下方逐項評估）。

### Uiverse（uiverse.io）

- **性質**：社群投稿的 UI 小元件庫，每個元件可複製成 HTML/CSS、Tailwind、React 或 Figma。
- **分類**：按鈕、核取方塊、開關、卡片、載入動畫、輸入框、單選、提示框、表單、背景紋樣等，數千個。
- **授權：MIT**，可以自由使用、修改、散布（保留授權聲明）。
- **品質參差**：
  - 常寫死色碼，要改成我們的 token。
  - 常把原生 input 藏起來卻沒有 focus 樣式，要補無障礙。
  - 很多是展示用的誇張效果。
- **對我們**：適合挑**開關、核取方塊、提示框、骨架載入、背景紋樣**的做法當參考。

資料取得說明：這三個網站從開發沙箱連不到，所以改用 GitHub Actions 的 probe workflow 取回頁面（uiverse.io 回 403 擋掉）。Vue Bits 的 README、授權全文，以及 React Bits 的元件目錄都有取回；其餘資訊來自搜尋結果（連結在文末）。

## 評估標準

每個點子都用這四點檢查：

1. **符合設計原則**：
   - 內容（地圖、照片、地名）是主角。
   - 不用漸層、毛玻璃、sparkle、emoji（§12）。
   - 動態只用在 sheet 展開、面板切換、地區色過場，150～250ms，不彈跳、不縮放、不視差（§9）。
2. **有意義**：動畫要傳達狀態改變（蓋了章、換了地區、切了段落），不是裝飾。
3. **效能**：手機上旅途中使用，不加 WebGL 背景，不增加大型套件。目前前端只依賴 Vue、Pinia、Vue Router、MapLibre、Firebase。
4. **無障礙**：`prefers-reduced-motion` 時一律關閉或改成淡入淡出；鍵盤可操作。

## 可以採用的（依建議優先順序）

### 1. 去過的「蓋章」動畫 ★

- **參考**：React Bits 的 StickerPeel、Magnet 等「按下有回饋」的互動。我們把這個概念轉成日本旅行的語彙：**橡皮章壓下去**。
- **現況**：按「去過」只是圖示瞬間換成實心圓。DESIGN.md §7.12 已經把「去過」定義成印章 Stamp，是品牌元素。
- **做法**：
  - 印章從稍大、稍透明壓到原尺寸，約 180ms。
  - 邊緣墨色略深一瞬間後褪回，約 300ms。
  - 同時輕微壓下的位移（1px）。
  - 只在「由沒去過變去過」時播放；取消時直接淡出。
- **位置**：景點卡片的「去過」、清單列的去過快捷鈕、擴充包清單（城集章）。
- **要改的規範**：§9「不做縮放」。建議把「蓋章」列為唯一例外，寫進 §9。**需要你決定**。
- **成本**：小，純 CSS keyframes＋一個 class。

### 2. 地圖 ↔ 深度探索的畫面銜接

- **參考**：motionsites.ai 範例常見的「元素在頁面間延續」的轉場；React Bits 的 AnimatedContent。
- **做法**：
  - 用瀏覽器內建的 **View Transitions API**（`document.startViewTransition`），在 Vue Router 換頁時啟動。
  - 地區標籤的縣名與深度探索頁的大標題設同一個 `view-transition-name`，瀏覽器自動讓它從小變大、從左上移到位置。
  - 其他內容淡入淡出，200ms。
- **好處**：
  - 「地名就是設計」（§1 第 3 點）的具體呈現。
  - 使用者清楚知道自己還在同一個地區，只是換了看法，解決剛才「返回和入口離很遠」的迷失感。
- **相容性**：
  - 不支援的瀏覽器直接換頁，沒有副作用。
  - reduced motion 時停用。
- **要改的規範**：§9 允許的範圍加上「頁面轉場（同一地區的地圖與深度探索）」。
- **成本**：小到中，不需要套件。

### 3. 會動的指示線與滾動數字

- **參考**：
  - React Bits 的 PillNav、FlowingMenu：目前選取的底線或底色滑到新項目。
  - React Bits 的 Counter、CountUp：數字滾動。
- **做法**：
  - **指示線**：景點類型分頁（不限、寺社、城・史跡…）、擴充包組別、深度探索與旅前準備的段落目錄，底線從舊位置滑到新位置，200ms，`ease-out-soft`。
  - **滾動數字**：換地區時擴充包按鈕上的件數（寶可夢 52 → 10）、城的「去過 12」，數字像計數器一樣往上翻，200ms。
- **要改的規範**：屬於「面板切換」的範圍，§9 可涵蓋；建議明文寫入。
- **成本**：小。

### 4. 和風紋樣與紙張質感（靜態）

- **參考**：Uiverse 的 patterns 類（CSS 背景紋樣）；React Bits 的 Noise（底片顆粒）、Topography（等高線）。
- **做法**：
  - **地區海報區**（地區標籤、深度探索頁標頭、行程封面）加極淡的傳統紋樣：青海波、麻の葉、市松、七宝。
    - 用 CSS 或 SVG 畫，顏色取地區色的 `accent`，透明度由 token 產生，不寫死。
  - 或改成**細微紙紋**（SVG feTurbulence 產生），讓海報區有印刷品、旅遊書的觸感。
  - **等高線**也適合空狀態、開場畫面的背景，和「地圖」的主題一致。
  - 全部靜態，不動（React Bits 的版本都是會動的 WebGL，我們只取圖樣）。
- **要改的規範**：不衝突（不是漸層、不會動）；DESIGN.md 需要新增「紋樣」一節，規定只用在海報區、每個地區固定一種或全站一種。
- **成本**：小到中（畫紋樣 SVG）。**需要你選**：紋樣或紙紋、全站一種或依地方（北海道、東北…）分配。

### 5. 骨架載入取代「載入中」

- **參考**：Uiverse 的 skeleton 載入元件。
- **現況**：9 處顯示純文字「載入中」，例如景點卡片、擴充包清單、搜尋、旅前準備、收藏清單。
- **做法**：
  - 顯示和內容同形狀的灰塊，例如清單列（圓角照片方塊＋兩行字）、景點卡片（照片區＋名稱區）。
  - 底色 `surface`，只有很慢的明暗呼吸，reduced motion 時靜止。
- **要改的規範**：§9 已允許「skeleton 閃爍動畫」。
- **成本**：小。

### 6. 練習卡的翻面與滑動（手機）

- **參考**：React Bits 的 Stack（可滑動的卡片堆）、CardSwap。
- **現況**：旅前準備的練習卡按一下就瞬間換成背面；答對、答錯要按按鈕或方向鍵。
- **做法**：
  - 翻面用 3D 翻轉，250ms。
  - 手機上往右滑是「記得」、往左滑是「再練」，卡片跟著手指移動，放開後飛出。
  - 保留按鈕與鍵盤操作。
- **要改的規範**：§9 需要允許「卡片翻面」。
- **成本**：中（手勢處理）。這是功能提升，不只是好看：旅途中單手就能練習。

### 7. 深度探索頁的海報區加代表照片

- **參考**：motionsites.ai 大部分 hero 範例的版面：大字＋一張全寬照片。
- **做法**：
  - 深度探索頁標頭右側（或底層）放該縣分數最高景點的 Commons 照片。
  - 疊上地區色，照片不壓過縣名。
  - 作者與授權照舊標示。
- **要改的規範**：不衝突（照片本來就是主角之一）。
- **成本**：小。

### 8. 其他小項目

- **翻牌字（Split-flap）**：參考 React Bits 的 SplitFlapText（車站發車看板的翻牌字）。
  - 和鐵路、旅行很搭，但動作明顯。
  - 若要用，只放在一個地方，例如行程頁的「出發倒數 12 天」。
  - 需要 §9 例外。
- **開場畫面的環狀文字**：參考 React Bits 的 CircularText。開場的圓圈（一巡り）外圍排一圈「ひとめぐり・HITOMEGURI・」，靜態或非常慢地轉。
- **提示框**：參考 Uiverse 的 tooltip。圖示按鈕（去過、設定）目前用瀏覽器原生 title，可換成和介面一致的小提示框（仍保留 aria-label）。
- **開關與核取方塊**：擴充包設定選單目前用原生 checkbox。可參考 Uiverse 做成主題色的開關，但要保留原生 input 與 focus 樣式。

## 不採用的，與原因

| 類型 | 例子 | 原因 |
|---|---|---|
| 漸層、光澤文字 | GradientText、ShinyText、Aurora、Plasma、Iridescence | §12 禁止漸層；「AI 味」的典型 |
| 玻璃擬態 | GlassSurface、FluidGlass、GlassIcons | §12 禁止毛玻璃 |
| 游標特效 | BlobCursor、SplashCursor、GhostCursor、ClickSpark、ImageTrail | 裝飾性、干擾地圖操作；手機沒有游標 |
| WebGL 背景 | Galaxy、Hyperspeed、LiquidChrome、Ballpit、Beams | 耗電、增加 three.js／ogl（數百 KB）；旅途中手機使用不合適 |
| 駭客、故障風文字 | DecryptedText、GlitchText、LetterGlitch、FaultyTerminal | 風格不符 |
| 彈跳、3D 傾斜 | BounceCards、TiltedCard、ProfileCard、Lanyard、Dock | §9 禁止彈跳、縮放 |
| sparkle | StarBorder、ClickSpark | §12 禁止 sparkle |
| 捲動視差、捲動浮字 | ScrollFloat、ScrollVelocity、ScrollStack | §9 禁止視差；資訊頁要能快速掃讀 |
| AI 首頁 prompt | motionsites.ai 全部 | 付費、行銷頁導向、影片背景 |

## 實作原則（如果要做）

- **自己寫**：每個效果寫成一個小 Vue 元件或 CSS utility，不引入 GSAP、motion、three.js、ogl。
  - Vue Bits 的授權（MIT + Commons Clause）禁止再散布元件本身；我們的 repo 公開，**不複製它的程式碼**，只參考效果。
  - Uiverse 是 MIT，可以參考或改寫；有直接沿用的片段時在檔案開頭註明來源與授權。
- **token 化**：顏色、時長、easing 一律用 `theme.css` 的 token（`--ease-out-soft`、地區色、主題色），不寫死。
- **reduced motion**：每個動畫都要在 `prefers-reduced-motion: reduce` 時關閉，或改成單純淡入淡出。
- **一次一個**：先做蓋章與頁面轉場，上線看感覺，再決定其他項目；DESIGN.md §9 同步更新允許的範圍。

## 需要你決定的

1. **§9 的例外**：是否允許以下幾種動畫：
   - 「蓋章」（縮放＋墨色）
   - 「頁面轉場」（地圖 ↔ 深度探索）
   - 「練習卡翻面、滑動」
   - 「翻牌字」
2. **紋樣**：要紋樣還是紙紋？全站一種，還是依地方分配不同紋樣？
3. **先做哪幾項**：我的建議順序是 1 → 2 → 3 → 5 → 4 → 6 → 7。
