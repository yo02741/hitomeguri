# 照片來源：各縣觀光照片庫與農林水產省（2026-11-06 調查）

地區特色（郷土料理、特產）約 1,300 項沒有照片，Commons 補了 333 張（`seed-specialty-photos`），剩下的要靠各地的觀光照片庫或農林水產省。

**可信度**：雲端沙箱連不到這些網站，以下是從搜尋結果的摘錄整理的，日文引文是摘錄，不是讀過全文。申請或使用前，請在瀏覽器把規約全文讀一遍。「?」表示沒查到，不是沒有。

## 共通的限制

- 幾乎每一家都寫「限用於本縣的觀光 PR／觀光振興」。ひとめぐり 是給台灣人的非營利旅前準備網站，應該符合（推測），但沒有一家明寫「海外、非日文網站」，最好寫信確認並留下回覆。
- 都沒有 API，只能人工挑照片、下載。多數禁止直接連結（hotlink），照片要放在我們自己的主機（Firebase Hosting）。
- 拍到寺社、店家、設施的照片，常要另外向設施申請（嚴島神社、金刀比羅宮、永平寺、奈良公園…）。
- 不能把照片本身當商品（明信片、月曆、素材集）。

## 農林水產省「うちの郷土料理」：料理照片最多

- 1,365 道料理都有照片，跟我們的地區特色幾乎一一對應。
- 網站寫「ダウンロードできる画像は二次利用も可能です」，但全站規約說照片「第三者が権利を有している場合が多いため…あらかじめ担当課に確認してください」，部分英文頁寫不能下載。所以要一次寫信問清楚。
- 窗口：大臣官房 新事業・食品産業部 外食・食文化課 食文化室，03-3502-5516（直通）。
- 另外「農山漁村の郷土料理百選」的照片要交「利用申請書」。

## 拿到照片之後

照片要人工挑（一道料理一張），放進資料時寫上來源、作者或提供者、取得日期與授權條件；顯示時照各家規定標示。程式這邊可以做：讀一個「料理 id → 照片檔、提供者、標示文字」的對照表，轉成縮圖放上 Hosting、寫進 `data/specialties/`。
